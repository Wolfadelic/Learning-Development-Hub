Accordion

Organise detailed information into sections learners can open when they need it.

What makes an effective learning interaction?

An effective interaction has a clear purpose, simple instructions, meaningful learner action, and feedback that supports the learning objective.

When should I use an accordion?

Use it for related information that learners may want to explore selectively. Avoid hiding essential instructions or making learners open many panels to complete a task.

What should I avoid?

Avoid vague labels, excessive nesting, and content that is difficult to compare because it is spread across closed panels.

Tabbed content

Present a small set of related topics without overwhelming the page.

Start with purpose

Every interaction should help the learner practise, apply, retrieve, or reflect on something that matters.

Make the learner act

Ask learners to make a choice, reveal an answer, sort information, or explain a decision—not simply click to continue.

Close the learning loop

Feedback should explain the result and guide the learner towards the intended understanding or next step.
