# Changelog

All notable changes to this repository will be documented in this file.

The format is based on the principles of Keep a Changelog. Dates use `YYYY-MM-DD`.

## [Unreleased]

### Added
- Configurable scenario engine with separate scenario data, decision and information nodes, branching, feedback, retry, outcomes, restart, and progress events.

### Added
- Branching eBilling invoice-rejection scenario with two decisions, feedback, retry paths, completion tracking, and restart.


### Changed
- Refined reusable tab, flashcard, and knowledge-check behaviour for independent component instances.
- Updated progress tracking to calculate its total from the available interactive activities.
- Improved selected-answer states and documented the manual QA process.
- Corrected component demo markup and advanced the demo label to version 0.2.


### Added
- Initial repository overview and planned folder structure.
- Baseline Git ignore rules.
- Contribution guidelines for human and AI-assisted development.
- Changelog for tracking future project updates.
- Project plan for the reusable interactive learning component library.
- Browser-based component demo with accordion, tabs, flashcard, knowledge check, and progress indicator.
- Hybrid theme styles and responsive layout.
- Dependency-free JavaScript interactions with keyboard support and learner feedback.
- Manual GitHub Pages workflow to publish the component library preview.
